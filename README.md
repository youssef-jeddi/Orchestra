# Orchestra

An always-on AI financial agent that manages your onchain portfolio via natural language. Talk to it like an assistant — "send 10 USDC to marc.eth", "find me a better vault" — and it handles everything autonomously, with physical Ledger hardware approval for high-value or high-risk transactions. Built with three OpenClaw agents (ElizaOS) coordinating through 0G Storage, executing swaps via Uniswap, and secured by a Safe smart account with tiered signing.

## Tracks

- **0G** — Decentralized inference via 0G Compute, shared agent memory via 0G Storage
- **Uniswap** — Real swap routing and quotes via the Uniswap API
- **Ledger** — Hardware approval for risky transactions via Ledger Device Management Kit
